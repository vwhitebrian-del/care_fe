# تشغيل نظام مستشفى سويد على اللاب توب (ويندوز)

**المتطلبات:** ويندوز 10/11 (64-بت)، ذاكرة 8 GB فأكثر، اتصال إنترنت أول مرة، ومساحة 15 GB.

1. حمّل مجلد المشروع (`git clone` أو ملف ZIP من فرع `arabic-rtl`).
2. افتح المجلد `deploy\windows` وانقر مرتين على **setup.bat**.
   - إن لم يكن Docker مثبتاً سيثبّته (winget) ثم يطلب إعادة تشغيل الجهاز؛ بعدها افتح Docker Desktop مرة واحدة وشغّل setup.bat ثانية.
3. اختر كلمة مرور لمدير النظام عندما يُطلب. بعدها يفتح المتصفح على النظام.
4. الدخول: باسم الدخول وكلمة المرور اللذين أدخلتهما (مدير النظام بكل الصلاحيات). ينشئ setup أيضاً المستشفى والأقسام (37) والطوابق والأسرّة.

**يومياً:** `start.bat` للتشغيل و`stop.bat` للإيقاف و`backup-now.bat` لنسخة احتياطية فورية.
النسخة اليومية التلقائية (03:00) تُحفظ في `deploy\backups` ما دام الجهاز شغّالاً.

**من التابلت:** على نفس شبكة الواي فاي افتح `http://<عنوان اللاب توب>` (يطبعه setup في آخر الإعداد؛ ويوجد في `deploy\.env` عند BUCKET_EXTERNAL_ENDPOINT).
قد يسأل جدار حماية ويندوز عن السماح، فاختر «شبكة خاصة».

**قارئ الباركود:** يُوصَّل بمنفذ USB ويعمل مباشرة كلوحة مفاتيح داخل أي حقل بحث.

> النظام يبدأ فارغاً (بلا مرضى). أنشئ المستشفى والأقسام من واجهة النظام، أو نستورد بياناتك لاحقاً.

## إضافة الأطباء والموظفين
افتح `deploy\staff.csv` بـ Excel (الأعمدة: الدور، الاسم، اسم الدخول، كلمة السر، القسم، الجنس، الهاتف) واملأ سطراً لكل شخص،
ثم انقر مرتين على `windows\add-staff.bat`. يتخطى الموجودين ويعرض النتيجة.
- الدور: طبيب، ممرض، محاسب، استقبال، صيدلي، موظف، مدير.
- اسم الدخول: حروف إنكليزية وأرقام و - و _ فقط (بلا نقطة).
- كلمة السر: 8 أحرف فأكثر وليست شائعة أو أرقاماً فقط. القسم والجنس والهاتف اختيارية.
- تعديل الصلاحيات لاحقاً من الواجهة (الإعدادات > الأدوار والمستخدمون).


## إن فشل تثبيت Docker تلقائياً
حمّل Docker Desktop يدوياً من https://www.docker.com/products/docker-desktop ثم ثبّته وأعد التشغيل وشغّل Docker Desktop مرة واحدة، ثم أعد تشغيل setup.bat.
